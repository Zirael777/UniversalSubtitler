# 🎬 Universal Subtitler (OpenClaw Skill)

Автоматический локальный генератор субтитров со встроенным умным переводчиком для видео из VK, YouTube или локальных файлов. Разработан как автономный скрипт и полностью оформлен в виде готового навыка (скилла) для ИИ-ассистента **OpenClaw**.

## ✨ Особенности
* **100% Бесплатно и локально:** Распознавание речи работает прямо на вашем компьютере с помощью нейросети `faster-whisper` без каких-либо сторонних платных API-ключей.
* **Умный перевод контекста:** Интегрирован движок `MyMemory Translator`, который переводит не просто отдельные слова, а понимает кино-контекст, разговорные выражения, идиомы и сленг.
* **Сохранение оригинала:** Скрипт всегда оставляет оригинальную дорожку (например, итальянскую) и создает рядом вторую качественную копию на выбранном языке.
* **Оптимизированные кино-тайминги:** Параметры Whisper настроены на более короткие, легко читаемые фразы без слипания текста в минутные куски.
* **Человеческие названия:** Файлы видео и субтитров сохраняются с реальным красивым названием фильма прямо с сайта (с автоматической защитой от сбоев кодировки Windows).

## 🛠 Требования и установка
1. Убедитесь, что в вашей системе установлен **FFmpeg** и путь к нему добавлен в переменные среды (PATH).
2. Установите необходимые библиотеки Python:
```bash
pip install faster-whisper deep-translator yt-dlp ffmpeg-python 
```

## 🚀 Использование через консоль (main.py)
Вы можете использовать проект как самостоятельную утилиту без запуска ассистента:
**Автоопределение языка оригинала и перевод на русский (по умолчанию):**
```bash
python main.py "[https://vkvideo.ru/ссылка_на_видео](https://vkvideo.ru/ссылка_на_видео)"
```

**Перевод на любой другой язык (например, английский, испанский, немецкий):**
Просто передайте двухбуквенный код целевого языка в параметр --to_lang:
```bash
python main.py "https://vkvideo.ru/ссылка_на_видео" --to_lang en
```
## ⚠️ Важное примечание для пользователей из РФ
При скачивании видео с **YouTube** утилита yt-dlp может работать крайне медленно или выдавать ошибку подключения из-за текущих ограничений и замедления платформы в России.
* **Решение:** Перед запуском скрипта для YouTube-ссылок убедитесь, что у вас включен системный VPN или настроены соответствующие прокси в терминале. Для видео из VK включать VPN не требуется.

## 🤖 Интеграция с OpenClaw
Проект полностью подготовлен для копирования в директорию навыков вашего ассистента.

**Структура репозитория**
* engine/subtitler.py — ядро распознавания речи, фильтрации тишины и контекстного перевода фраз.
* skills/universal_subtitler/ — манифест (manifest.json) и точка входа (__init__.py) для интеграции в OpenClaw.
* main.py — скрипт для независимого локального запуска.

**Примеры команд для ИИ-ассистента:**
* «Сделай русские субтитры для этой ссылки...»
* «Скачай видео и распознай итальянский текст...»
* «Переведи это видео на английский...»
