# 🎬 Universal Subtitler (OpenClaw Skill)
Автоматический локальный генератор субтитров со встроенным умным переводчиком для видео из VK, Rutube или локальных файлов.

## ✨ Особенности
* **100% Локально:** Распознавание речи работает на вашем компьютере с помощью `faster-whisper`.
* **Надежный перевод:** Интегрирован движок `GoogleTranslator` для качественного перевода кино-контекста.
* **Сохранение оригинала:** Скрипт всегда создает оригинальную дорожку субтитров и её переведенную копию.
* **Умная геолокация:** Автоматически определяет регион пользователя, защищая от скрытых блокировок платформ.

## 🚀 Использование через консоль (main.py)
**Запуск по ссылке (VK / Rutube):**
```bash
python main.py "[https://vkvideo.ru/ссылка_на_видео](https://vkvideo.ru/ссылка_на_видео)"
```

**Запуск локального файла (Рекомендуется для YouTube в РФ):**
```bash
python main.py "C:\Movies\clip.mp4" --to-lang en
```

**Перевод на любой другой язык (например, английский, испанский, немецкий):**
Просто передайте двухбуквенный код целевого языка в параметр --to_lang:
```bash
python main.py "https://vkvideo.ru/ссылка_на_видео" --to_lang en
```

## ⚠️ Важное примечание для пользователей из РФ
Прямая загрузка с YouTube в России ограничена на уровне провайдеров. Скрипт автоматически определит ваш регион и заблокирует нестабильное скачивание по ссылке во избежание бесконечных ошибок.
* **Решение:** Просто скачайте видеофайл самостоятельно любым удобным способом и укажите локальный путь к нему вместо ссылки.

## 🤖 Интеграция с OpenClaw
Проект полностью подготовлен для копирования в директорию навыков вашего ассистента.

**Структура репозитория**
* engine/subtitler.py — ядро распознавания речи, фильтрации тишины и контекстного перевода фраз.
* skills/universal_subtitler/ — манифест (manifest.json) и точка входа (__init__.py) для интеграции в OpenClaw.
* main.py — скрипт для независимого локального запуска.

**Примеры команд для ИИ-ассистента:**
* «Сделай русские субтитры для этой ссылки...»
* «Скачай видео и распознай итальянский текст...»
* «Переведи это видео на английский...»
